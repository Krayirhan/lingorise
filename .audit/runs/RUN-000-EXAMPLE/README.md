# Example Run Directory

This directory demonstrates naming only. Replace with real immutable runs such as:

```text
RUN-001-BASELINE
RUN-002-REAUDIT
RUN-003-CERTIFY
```

A completed baseline normally contains:

```text
01_PROJECT_UNDERSTANDING.md
02_PROJECT_PURPOSE.md
03_AUDIT_SCOPE_AND_RISK.md
04_CONTEXTUAL_RUBRIC.md
05_TOOL_AND_GRAPH_ANALYSIS.md
06_EVIDENCE_INDEX.md
07_DETAILED_AUDIT.md
08_SCORECARD.md
09_FINDINGS.md
10_ACTION_PLAN.md
11_RELEASE_VERDICT.md
```

Re-audit additionally contains:

```text
12_DELTA_REPORT.md
13_REGRESSION_REPORT.md
```
