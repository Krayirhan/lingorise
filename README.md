# LingoRise

LingoRise, İngilizce öğrenmeyi kısa, eğlenceli ve seviyeye dayalı mobil oyunlarla destekleyen global bir öğrenme uygulamasıdır.

## Hedef

Kullanıcıların A1'den C2'ye kadar kelime bilgisi, cümle kurma, gramer, dinleme ve anlamlandırma becerilerini oyunlaştırılmış tekrarlarla geliştirmek.

## İlk çalıştırma

Node.js 20+ ve Expo Go kurulu bir mobil cihaz/emülatör gerekir.

```bash
npm install
npm start
```

Terminaldeki QR kodu Expo Go ile tarayın veya `a` (Android), `i` (iOS) tuşlarını kullanın. Tip kontrolü için `npm run typecheck` çalıştırın.
